# Boss 搜索执行参考

## 搜索前

- 必需条件只有职位关键词。城市未给出时可以沿用页面当前城市；页面也没有证据时再询问。
- 数量未给出时，先整理当前可见结果，不擅自承诺遍历全部结果。
- “AI Agent 方向”“不要外包”“双休”等属于语义条件，不能假装 Boss 原生筛选器一定支持。

## 搜索与列表

1. 优先一次调用 `browser_action.search(destination="boss", query=...)`，不要先打开再搜索。
2. 搜索工具验证失败时，读取它返回的原因；只在引用过期、页面加载中或目标歧义时选择对应恢复动作。
3. 使用 `read_current_page` 获取当前列表的结构化增强。
4. 用户只要求概览时直接整理可见列表；用户明确要求更多结果时，才滚动或翻页。
5. 每次页面动作后使用最新观察，不复用旧 ref。

## 岗位详情

- 需要判断技术栈、工作职责、外包/驻场、福利或经验要求时，应进入岗位详情或读取当前展开详情。
- 打开详情后确认标题或 URL 已变化，再读取正文。
- 页面只显示部分 JD 时，标注“基于当前可见内容”，不要补全未知部分。

## 失败恢复

- 验证码：停止并请用户亲自完成。
- 登录、密码、附件：请用户亲自处理。
- 页面结构变化：从 `observe_page` 重新建立引用；只有视觉信息无法由 DOM 表达时再请求截图。
- 多个候选标签页或控件：调用 `ask_user`，不要猜。
