# 调研报告模板（summary-guide）

所有脚本运行结束后，按此模板输出最终报告。**事实与推断必须分开标注。**

## 报告结构

```markdown
# [博主昵称] 笔记调研报告

## 博主画像
- 昵称/小红书号/IP/简介（来自 read 或 collect 的 profile 数据，缺失写「未采集」）
- 关注/粉丝/获赞与收藏/笔记数

## 采集概况
- 模式（指定数量/自由探索）、目标数量、实际收集、实际深入阅读篇数
- 中止原因（正常结束/到底/改版/验证码）

## 笔记概览（表格）
| # | 标题 | 点赞 | 视频/图文 | 评论数（如读取） |

## 主题归纳
- 高频选题方向（按标题聚类，标注这是你的推断）
- 内容形态分布（视频 vs 图文比例，基于 hasVideo 与 mediaKind）

## 数据洞察
- 互动量分布：最高/最低/中位数（基于 likes 数字，注明解析口径）
- 评论洞察（仅统计实际读取的篇目）：共 X 条，正向/负向/提问类占比是你的推断

## 信息缺口
- 未读取的篇目数量及原因
- 字段缺失列表（如某些卡片无标题/无点赞）

## 原始数据
- 工作区文件路径（如已运行 save-results.js）
```

## 写作规范

- 表格中的数字必须来自脚本返回；无法换算的原始字符串照抄（如「1.2万」），不要臆造精确值。
- 「主题归纳」「数据洞察」里属于推断的句子，用「（推断）」标注。
- 报告要能独立成文：不引用中间对话，不出现「如上所述」。
- 少于 3 篇时不用完整模板，给精简版（画像 + 列表 + 一句话观察）。
